由展開倒過來

甚麼是因式分解？

先用一個較簡單的式子看看。展開，是把乘積寫成各項的和；因式分解就是倒過來，找出相乘的因式。

分配律：兩個方向都成立a(b + c) = ab + ac

同一個 a 分別乘 b、c；倒過來可提出 a。

因式分解不是解方程。題目只有多項式，沒有等號時，不需要求 x 的值。

這三個答案，你會給哪個滿分？

把 6x + 12 完全因式分解。

留意「相等」和「已完全分解」是兩件不同的事。

每項都有甚麼？

先找最大公因式

  1. 數字：找各項係數的最大公因數。
  2. 字母：只取每一項都有的字母，並取其最低次數。
  3. 每一項除以公因式，所得結果放入括號。

回到開頭那題：兩項都有公因數 2。

2x2 − 18
= 2(x2 − 9)

這一步正確，但還未做完。先記住括號裏的 x2 − 9，到了恆等式再回來看。

例 1 · 數字與字母一起提取

6x2y + 9xy2

6 和 9 的最大公因數是 3；兩項都有 x 和 y，最低次數都是 1。

最大公因式：3xy6x2y + 9xy2
= 3xy(2x + 3y)

兩項都有 3xy；各自除以它，所得結果放進括號。

展開驗算

3xy × 2x + 3xy × 3y
= 6x2y + 9xy2

兩塊拼起來，總闊度會是甚麼？

分開計面積：把兩項相加。合起來計面積：共同高度 × 總闊度。

有人這樣寫（錯誤）5x + 5 = 5x

那個 5 沒有消失。
它除以公因數 5，留下的是 1。

應寫成5(x + 1)

展開才會回到原式。

遇到負數：提取 −1 有甚麼作用？

3 − x = −(x − 3)

提出負號時，括號內每一項都要變號。例如：

−4x2 + 8x = −4x(x − 2)

換一題，遇到四項怎麼辦？

四項多項式：分組法

不是每題都能一次提出公因式。若四項沒有共同因式，先分成兩組；每組各自提取後，再看看有沒有留下同一個括號。

先分成兩組 ax + ay + bx + by
提出 a提出 b
各組提出公因式 a(x + y) + b(x + y)
兩組同一個括號，提出一次↓
合成結果= (a + b)(x + y)

前兩項提出 a，後兩項提出 b；兩組留下同一個括號。

你會先把哪兩項放在一起？

例 2 · 括號的次序相反

a(x − y) + b(y − x)
= a(x − y) − b(x − y)
= (a − b)(x − y)

(y − x) = −(x − y)；先變成相同括號，再提出來。

(y − x) = −(x − y)，不能直接當作相同括號。

開頭的括號，原來還有一步

把恆等式倒過來用

還記得 x2 − 9 嗎？9 就是 32，所以它是兩個平方相減。先認出平方差，再看看三項的完全平方：首末項都要是平方，中間項還要配得上 ±2ab。

平方差：兩項、相減、各自是平方a2 − b2 = (a + b)(a − b)

展開時 +ab 和 −ab 抵消，留下兩個平方之差。

完全平方：加a2 + 2ab + b2 = (a + b)2

(a + b)2 有 a2、兩份 ab 和 b2。

完全平方：減，中間項是 −2aba2 − 2ab + b2 = (a − b)2

(a − b)2 的兩個交叉項都是 −ab，合成 −2ab。

這題像哪一個恆等式？

回到開頭那題：現在可以分解到底了

提出 2 之後，括號裏的平方差還可以再拆。兩步要一起保留。

2x2 − 18
= 2(x2 − 9)
= 2(x + 3)(x − 3)

先提出公因數 2，再把括號內的平方差分解，才是完全因式分解。

有人這樣寫（錯誤）x2 + 9
= (x + 3)(x − 3)

先展開，不要只看它長得像。

右邊展開會得到 x2 − 9，正負號對不上。平方和不是平方差。

重溫恆等式的面積圖解

先選方法，再動筆

完全分解，展開驗算

  1. 先看公因式。 每題都先檢查能否提取。
  2. 兩項：看看是否平方差。
  3. 三項：看看是否完全平方。
  4. 四項：嘗試分組，找出共同括號。
  5. 最後檢查：還能再分解嗎？展開後是否回到原式？

綜合題 · 不要提早停下來

把 3x3 − 12x 完全因式分解。

完整解答

3x3 − 12x
= 3x(x2 − 4)
= 3x(x + 2)(x − 2)

先提出公因式 3x，再分解括號內的平方差。
