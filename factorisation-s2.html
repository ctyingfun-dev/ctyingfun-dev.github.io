多項式的因式分解

01 · 由展開倒過來

甚麼是因式分解？

展開時，把乘積寫成各項的和；因式分解則反過來，把多項式寫成因式的乘積。

分配律：兩個方向都成立a(b + c) = ab + ac

因式分解不是解方程。題目只有多項式，沒有等號時，不需要求 x 的值。

哪一個才是因式分解？

把 6x + 12 完全因式分解。

留意「相等」和「已完全分解」是兩件不同的事。

02 · 每項都有甚麼？

先找最大公因式

  1. 數字：找各項係數的最大公因數。
  2. 字母：只取每一項都有的字母，並取其最低次數。
  3. 每一項除以公因式，所得結果放入括號。

例 1 · 數字與字母一起提取

6x2y + 9xy2

6 和 9 的最大公因數是 3；兩項都有 x 和 y，最低次數都是 1。

最大公因式：3xy6x2y + 9xy2
= 3xy(2x + 3y)
展開驗算

3xy × 2x + 3xy × 3y
= 6x2y + 9xy2

面積圖：共同的高度，就是公因式

分開計面積：把兩項相加。合起來計面積：共同高度 × 總闊度。

提取後不能漏掉 1：5x + 5 = 5(x + 1)，不是 5x。

遇到負數：提取 −1 有甚麼作用？

3 − x = −(x − 3)

提出負號時，括號內每一項都要變號。例如：

−4x2 + 8x = −4x(x − 2)

03 · 把共同括號找出來

四項多項式：分組法

若沒有所有項都共有的因式，可先把各項分組。每組提取公因式後，看看能否出現相同的括號。

ax + ay + bx + by
= a(x + y) + b(x + y)
= (a + b)(x + y)

逐步拆解：先分組，再提取

例 2 · 括號的次序相反

a(x − y) + b(y − x)
= a(x − y) − b(x − y)
= (a − b)(x − y)

(y − x) = −(x − y)，不能直接當作相同括號。

04 · 認出熟悉的形狀

把恆等式倒過來用

平方差：兩項、相減、各自是平方a2 − b2 = (a + b)(a − b)
完全平方：中間項必須是 ±2aba2 + 2ab + b2 = (a + b)2
a2 − 2ab + b2 = (a − b)2

辨認模式，再揭曉因式

例 3 · 提取後，還可以再分解

2x2 − 18
= 2(x2 − 9)
= 2(x + 3)(x − 3)

先提出 2，再把括號內的平方差分解，才是完全因式分解。

x2 + 9 是平方和，不能寫成 (x + 3)(x − 3)。後者展開是 x2 − 9。

05 · 先選方法，再動筆

完全分解，展開驗算

  1. 先看公因式。 每題都先檢查能否提取。
  2. 兩項：看看是否平方差。
  3. 三項：看看是否完全平方。
  4. 四項：嘗試分組，找出共同括號。
  5. 最後檢查：還能再分解嗎？展開後是否回到原式？

綜合題 · 不要提早停下來

把 3x3 − 12x 完全因式分解。

完整解答

3x3 − 12x
= 3x(x2 − 4)
= 3x(x + 2)(x − 2)

先提出公因式 3x，再分解括號內的平方差。
