01 · 從展開看交叉乘積

十字相乘在檢查甚麼？

先展開一次：中間項從這兩個乘積而來(px + q)(rx + s)
= prx2 + (ps + qr)x + qs

左邊相乘得到首項，右邊相乘得到常數項；兩條對角線的乘積相加，必須得到中間項。最後沿每一橫行寫出一個因式。

02 · 首項係數為 1

乘積對了，兩數之和也對嗎？

x2 + bx + c = (x + m)(x + n)
mn = c，m + n = b

乘積是 +6，和是 +5：兩數應用甚麼符號？

兩數同號，而和為正，所以兩數均為正。

x2 + 5x + 6 = (x + 2)(x + 3)

2 × 3 = 6；2 + 3 = 5。

乘積仍是 +6，和變成 −5，符號要改嗎？

兩數同號，而和為負，所以兩數均為負。

x2 − 5x + 6 = (x − 2)(x − 3)

(−2) × (−3) = 6；−2 + (−3) = −5。

乘積是 −6，負號放在哪個數？

兩數必定異號。絕對值較大的數，決定兩數之和的正負號。

x2 + x − 6
= (x + 3)(x − 2)

x2 − x − 6
= (x − 3)(x + 2)

錯誤寫法x2 − 5x + 6 = (x + 2)(x + 3)

老師批註只驗算乘積還不夠。右邊展開的中間項是 +5x，題目卻是 −5x。常數為正，不代表兩數一定為正。

正確答案(x − 2)(x − 3)

這個「兩數之和」規則用於首項係數為 1。首項係數不為 1 時，要計算完整的交叉乘積。

03 · 首項係數不為 1

交換 1 和 3，中間項會一樣嗎？

以 2x2 + 7x + 3 為例，左邊可放 2x 和 x，右邊放 1 和 3。但右邊的位置不能隨便決定。

這個配對，真的得到 7x 嗎？

錯誤配對

正確答案2x2 + 7x + 3
= (2x + 1)(x + 3)

6 只試 1 × 6 就夠嗎？

6x2 + 11x + 3

6 可拆成 1 × 6 或 2 × 3。逐組嘗試，不能只試第一組便放棄。

(2x + 3)(3x + 1)
= 6x2 + 2x + 9x + 3
= 6x2 + 11x + 3

只算 2 + (−1)，真的能驗算中間項嗎？

6x2 + x − 2
= (3x + 2)(2x − 1)

交叉項為 −3x 和 4x，相加得到 x。不要只把 2 和 −1 相加作判斷。

04 · 先整理，再分解

畫十字之前，有甚麼要先提出來？

每項都有 2，先提出來會怎樣？

2x2 + 10x + 12
= 2(x2 + 5x + 6)
= 2(x + 2)(x + 3)

提出 −1，哪幾項要變號？

−x2 + 5x − 6
= −(x2 − 5x + 6)
= −(x − 2)(x − 3)

提出 −1 時，括號內每一項都要變號。

提出 3 之外，字母也找齊了嗎？

3x3 + 15x2 + 18x
= 3x(x2 + 5x + 6)
= 3x(x + 2)(x + 3)

錯誤寫法 · 漏了外面的因式2x2 + 10x + 12 = (x + 2)(x + 3)

老師批註十字圖只分解括號內的二次式。原先提出的 2 仍是整個答案的一部分，不可以丟掉。

正確答案2(x + 2)(x + 3)

05 · 零項、重複因式與整數配對

少了一項，或找不到配對，怎樣辦？

中間項不見了，是哪兩項抵消？

x2 − 9 = (x + 3)(x − 3)

交叉項 −3x 和 3x 抵消。能認出平方差時，可直接用恆等式。

兩行完全一樣，可以怎樣寫短一點？

x2 + 6x + 9 = (x + 3)2

常數項是零，還需要慢慢配對嗎？

2x2 + 7x = x(2x + 7)

試完所有整數配對，仍不合適呢？

x2 + x + 1

整數乘積為 1 的配對只有 1、1 或 −1、−1；和分別為 2 或 −2，都不是 1。因此不能分解成整數係數的一次因式乘積。

因式分解不是解方程。沒有等號時，答案是因式的乘積，不是 x 的值。
