02 · 圖解公式

恆等式為甚麼「恆」成立？

恆等式是把同一個數量用兩種方法表示。不論代入甚麼合適的數值，左右兩邊都相等。下面用長度和面積看三條公式；拖動 a、b，圖形和數值會一起改變。

面積圖解

圖中用正數長度，所以設定 a > b > 0。代數公式本身不只適用於這些數值。

03 · 連繫公式

三條常用恆等式

和的平方

(a + b)2 = a2 + 2ab + b2

四塊面積：一塊 a2、兩塊 ab、一塊 b2。

差的平方

(a − b)2 = a2 − 2ab + b2

從 a2 減兩條 ab 長條；重疊的 b2 要加回一次。

平方差

(a + b)(a − b) = a2 − b2

從大正方形拿走小正方形，剩下的面積可以拼成長方形。

04 · 小心陷阱

不要漏掉中間項

兩項相加後再平方

(a + b)2 ≠ a2 + b2。例如 (3 + 2)2 = 25，但 32 + 22 = 13。少了兩塊 ab。

留意正負號

(a − b)2 = a2 − 2ab + b2。最後的 b2 是正數項；但平方差的結果是 a2 − b2。
